Project: data center hardware trainer

An interactive break-fix lab built from real floor work. Dell PowerEdge only: break a server, read the alert, find the part, then repair it step by step. The whole rack sits right under the server — break any rack unit there too, so you can run server and rack errors from one place.

Whole rack — alongside SRV-01

One 42U rack, top to bottom, power at the bottom. Tap a unit to see what it does, Break it to run its error, Restore it to clear it, or Create ticket for it. The Servers unit is SRV-01 itself — its status follows the trainer server above, so a ticket fault on SRV-01 shows here too.

Restore clears the rack error. A ticket for that unit, if any, stays open so you can document and close it in Tickets.

    ESD and electrical hazard. Before opening a chassis for memory, processor or board work, power the server down, unplug all power cords and wear a grounded anti-static wrist strap.

    Trainer note: all faults, temperatures, part specs, and counts in the trainer are demo data, not from a real site. Simulation changes from the uploaded file: server model changed to generic PowerEdge, because only that family is in focus in this version; Inject-all relabelled to show it affects only the selected server; both power supplies failing via fault injection now powers the server off (pulling both out already did); reduced-motion mode now stops animations; a memory reboot flag clears if the fault is fixed early. Demo simplification: voltage and processor faults clear on first fix in the trainer, but in real life a remaining voltage fault means board replacement, and a recurring processor error means processor replacement.
